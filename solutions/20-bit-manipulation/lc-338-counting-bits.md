## 心得

這題我有兩種解都 AC。解法一是把每個數字轉成二進位，逐位數有幾個 `1`；解法二第一次真正用到位元運算，透過 `i >> 1` 拿掉最低位，再用 `i & 1` 判斷最低位是不是 `1`。位元運算目前是靠 AI 一步一步教我，所以保留完整的逐字註解，讓之後複習時可以重新走過理解過程。

## Java

### 解法一：逐位除 2（O(n log m)）

```java
class Solution {

    public int[] countBits(int n) {
        int[] res = new int[n + 1];

        for (int i = 0; i <= n; i++) {
            int bitCnt = 0;
            int num = i;
            while (num > 0) {
                bitCnt += num % 2;
                num /= 2;
            }
            res[i] = bitCnt;
        }

        return res;
    }
}
```

對每個 `i`，反覆用 `% 2` 取出最低位，再用 `/ 2` 移除最低位。若 `i` 的二進位長度是 `log m`，總時間是 `O(n log m)`；空間是輸出陣列 `O(n)`。

### 解法二：DP + 位元運算子（O(n)）

```java
/*
338. Counting Bits
二進制1個個數
0 <= n <= 10^5

i   bit  cnt 拆解                  dp
0   0    0   0                     dp[0] = 0
1   1    1   2^0                   dp[1] = dp[0] + (1 & 1) = 0 + 1 = 1
2   10   1   2^1                   dp[2] = dp[1] + (2 & 1) = 1 + 0 = 1
3   11   2   2^1+2^0               dp[3] = dp[1] + (3 & 1) = 1 + 1 = 2
4   100  1   2^2                   dp[4] = dp[2] + (4 & 1) = 1 + 0 = 1
5   101  2   2^2+2^0               dp[5] = dp[2] + (5 & 1) = 1 + 1 = 2
6   110  2   2^2+2^1               dp[6] = dp[3] + (6 & 1) = 2 + 0 = 2
7   111  3   2^2+2^1+2^0           dp[7] = dp[3] + (7 & 1) = 2 + 1 = 3
8   1000 1   2^3                   dp[8] = dp[4] + (8 & 1) = 1 + 0 = 1
9   1001 2   2^3+2^0               dp[9] = dp[4] + (9 & 1) = 1 + 1 = 2
10  1010 2   2^3+2^1               dp[10] = dp[5] + (10 & 1) = 2 + 0 = 2
11  1011 3   2^3+2^1+2^0           dp[11] = dp[5] + (11 & 1) = 2 + 1 = 3
12  1100 2   2^3+2^2               dp[12] = dp[6] + (12 & 1) = 2 + 0 = 2
13  1101 3   2^3+2^2+2^0           dp[13] = dp[6] + (13 & 1) = 2 + 1 = 3
14  1110 3   2^3+2^2+2^1           dp[14] = dp[7] + (14 & 1) = 3 + 0 = 3
15  1111 4   2^3+2^2+2^1+2^0       dp[15] = dp[7] + (15 & 1) = 3 + 1 = 4

n=7, ans=[0,1,1,2,1,2,2,3]
*/
class Solution {

    public int[] countBits(int n) {
        // 動態規劃陣列，用來在計算時複用已計算的結果
        // dp[i] 儲存整數 i 的二進位中「1 的個數」
        // 二進位中的 1 代表某個 2^bit 存在，例如 3(11) = 2^1 + 2^0
        int[] dp = new int[n + 1];

        for (int i = 0; i <= n; i++) {
            // 核心公式：
            // dp[i] = dp[i >> 1] + (i & 1)

            /**
             (1) i >> 1
                 - 右移一位，相當於整數除以 2。
                 - 直覺理解：當前數字除以 2 → 前面計算過的數字「全部進位」。
                 - 所以 dp[i >> 1] 就是「把前面算過的結果整個往前推一位」。
             舉例：
                 i      = 15 (1111) = 2^3 + 2^2 + 2^1 + (最低位)
                 i >> 1 = 7  (0111) = 2^2 + 2^1 + 2^0
                 → 可以看到 7 的位元全部進位，剛好成為 15 除以 2 的結果。

                 反推：7 << 1 = 1110 = 14
                 → 把 7 的位元全部往前進一位，剛好等於乘以 2。
                 → 就是 15 不計最低位的結果。
            */

            /**
             (2) i & 1
                 - & 是 位元 AND 運算：只有當兩邊都是 1，結果才是 1。
                 - i & 1 就是把 i 的所有位元和 1 (0001) 做 AND → 只留下最低位。
                 - 如果最低位是 1 → 結果是 1。
                 - 如果最低位是 0 → 結果是 0。
             舉例：
                 i      = 15 (1111)
                 i & 1  = (1111) & (0001) = (0001) → 最低位是 1
                 i      = 14 (1110)
                 i & 1  = (1110) & (0001) = (0000) → 最低位是 0
            */

            /**
             (3) 合起來：
                 - dp[i] = 前面計算過的數字全部進位 + 最低位的貢獻
                 - 直覺理解就是「前面結果進位 + 最低位」。
             舉例：
                 dp[15] = dp[7] + 1 = (前面算過的 7 進位結果) + (最低位判斷)
                 dp[14] = dp[7] + 0 = (前面算過的 7 進位結果) + (最低位判斷)
            */

            dp[i] = dp[i >> 1] + (i & 1);
        }

        return dp;
    }
}
```

#### 位元運算前置知識

**AND 運算 `&`**：兩個位元都為 `1`，結果才是 `1`。例如 `6 & 3`：`110 & 011 = 010`，結果是 `2`。常用來檢查某一位是否為 `1`，例如 `x & 1` 判斷奇偶。

**OR 運算 `|`**：只要有一個位元是 `1`，結果就是 `1`。例如 `6 | 3`：`110 | 011 = 111`，結果是 `7`。常用來把某一位「打開」。

**XOR 運算 `^`**：兩個位元不同，結果是 `1`；相同，結果是 `0`。例如 `6 ^ 3`：`110 ^ 011 = 101`，結果是 `5`。常用來切換某一位（toggle）。

**NOT 運算 `~`**：位元反轉，`0 → 1`、`1 → 0`。例如 `~6 → ...11111001`（依照補數表示法）。常用來快速取反，但要注意整數的補數表示。

**左移 `<<`**：所有位元往左移，右邊補 `0`。例如 `3 << 1`：`011 << 1 = 110`，結果是 `6`。常用來表示乘以 `2` 的次方。

**右移 `>>`**：所有位元往右移，左邊補符號位（正數補 `0`，負數補 `1`）。例如 `6 >> 1`：`110 >> 1 = 011`，結果是 `3`。正整數時可理解成整數除以 `2` 的次方。

**無號右移 `>>>`（Java 特有）**：所有位元往右移，左邊永遠補 `0`。例如 `-6 >>> 1` 會得到一個很大的正數，常用來處理無號整數的位移。

📌 **總結**：`&` → AND、檢查位元；`|` → OR、設定位元；`^` → XOR、切換位元；`~` → NOT、反轉位元；`<<` → 左移（乘 `2^n`）；`>>` → 右移（正數時可視為除 `2^n`，並保留符號）；`>>>` → 無號右移（左側補 `0`）。
