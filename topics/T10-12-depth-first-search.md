# Depth-First Search

## 解題技巧

DFS 常以遞迴維護子樹的狀態與回傳條件。一題同時包含「搜尋候選位置」與「驗證候選結構」時，可以拆成兩個職責單純的遞迴函式，並用 `||` 或 `&&` 短路。
